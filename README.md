# PS Estética

Site, quiz de captação e painel administrativo da PS Estética.

## Configuração

1. Copie `.env.example` para `.env.local`.
2. Preencha as variáveis públicas do Supabase.
3. Execute `npm install` e `npm run dev`.

O banco de dados, a autenticação e os leads permanecem hospedados no Supabase.
